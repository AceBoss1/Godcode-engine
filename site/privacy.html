The short version

God Code is a programming language and learning site. We collect almost nothing. There are no accounts, no analytics trackers, and no advertising. This page describes the little we do handle.

The playground

The code you write in the playground runs entirely in your own browser. It is never sent to our servers. If you use a share link, your code is encoded into the link itself, so anyone opening that link receives the code as part of the address. Only share links containing code you are happy to make public.

The scroll registry

Publishing a scroll to the public registry stores its name, description, author name, and code, so others can discover and run it. Publishing requires an author token. Published scrolls are public by design. If you need a published scroll removed, write to hello@getgodcode.com.

What we do not do

  • No Google Analytics, Meta Pixel, or any third-party tracking.
  • We do not sell personal information. We barely collect any.
  • We do not run advertising on this site.

Community spaces

Our Discord server and GitHub organisation are run on those platforms and governed by their own privacy policies. What you post there is subject to their rules.

Your rights

Because we hold almost no personal data, there is little to request. For anything we do hold (for example, a published scroll attributed to you), write to hello@getgodcode.com and we will help.
