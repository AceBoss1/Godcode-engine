Something new landed today, and it is close to my heart.

From the beginning, God Code was built for humans and AI creating together. Today that promise grows teeth. We have shipped a skill pack that teaches your AI assistant to write God Code: to generate scrolls, check them with the engine, fix them from the engine's own hints, and run them safely in the sandbox.

It works with the assistants people already use. Muse, Claude Code, Cursor, Codex, and more. One installer detects your tools and sets everything up. If you use Claude Code, it is two commands:

/plugin marketplace add godcodeengine/Godcode-engine /plugin install godcode@godcode-marketplace

Then ask your assistant to write a God Code scroll, and watch it generate, check, fix, and run. Every example in the pack was verified against the real engine before it shipped.

Alakanani

Why this matters

God Code was always meant to be the language agents speak: humans state their intent, grant narrow permissions, run safely, and leave a verifiable record of what happened. This skill pack is the first door into that future. Your AI does not just autocomplete God Code. It follows the whole loop the way a careful builder would: declare what the scroll may touch, check before running, and never run a stranger's scroll outside the sandbox.

Last night I watched the engine read a scroll whose declared intent was "bring peace to the household," and discern it back as "Blessing of peace." The thing understands what it reads. That is the moment I knew this was ready for you.
